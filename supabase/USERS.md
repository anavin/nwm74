# การเพิ่มผู้ใช้ (ไม่ต้องมีอีเมลจริง)

ผู้ใช้ล็อกอินด้วย **ชื่อผู้ใช้ + รหัสผ่าน** เท่านั้น ไม่ต้องมีอีเมล

Supabase Auth บังคับให้ทุกบัญชีมีอีเมล ระบบจึงใช้โดเมนภายในที่ไม่มีอยู่จริง
(`nm74.local`) ต่อท้ายให้อัตโนมัติ — ผู้ใช้ไม่เคยเห็นและไม่ต้องพิมพ์

| ผู้ใช้พิมพ์ | ระบบส่งไป Supabase | หน้าจอแสดง |
|---|---|---|
| `somchai` | `somchai@nm74.local` | `somchai` |
| `cm` | `cm@nm74.local` | `cm` |
| `anavin.st@gmail.com` | ใช้ตรงๆ (อีเมลจริงยังล็อกอินได้) | เต็มอีเมล |

เปลี่ยนโดเมนได้ที่ `config.js` → `USER_DOMAIN`
(ถ้าเปลี่ยน ต้องแก้อีเมลของผู้ใช้เดิมใน Supabase ให้ตรงกันด้วย)

---

## ก่อนเพิ่มผู้ใช้คนแรก — ปิดการสมัครเอง (สำคัญมาก)

คีย์ publishable อยู่ในหน้าเว็บ ใครก็อ่านได้ ถ้าเปิดให้สมัครเองไว้
คนที่รู้ URL จะสร้างบัญชีเองแล้วเห็นข้อมูลโครงการทั้งหมดได้

**Supabase → Authentication → Sign In / Providers → Email**

1. ปิด **Allow new users to sign up**
2. ปิด **Confirm email** (เพราะอีเมลภายในส่งจริงไม่ได้)
3. Save

หลังจากนี้บัญชีจะถูกสร้างได้จากหน้า Dashboard เท่านั้น

---

## เพิ่มผู้ใช้ทีละคน

**Supabase → Authentication → Users → Add user → Create new user**

| ช่อง | ใส่อะไร |
|---|---|
| Email address | `ชื่อผู้ใช้@nm74.local` เช่น `somchai@nm74.local` |
| Password | รหัสผ่านที่ตั้งให้ (อย่างน้อย 6 ตัว) |
| Auto Confirm User | **ติ๊ก** — ถ้าไม่ติ๊กจะล็อกอินไม่ได้ เพราะยืนยันอีเมลไม่ได้ |

กด **Create user** แล้วบอกคนนั้นว่า

> ชื่อผู้ใช้: `somchai`  รหัสผ่าน: `……`

ใช้ตัวพิมพ์เล็กและห้ามเว้นวรรคในชื่อผู้ใช้ (ระบบแปลงเป็นพิมพ์เล็กและตัดช่องว่างให้อยู่แล้ว)

## งานดูแลอื่นๆ

**เปลี่ยน / รีเซ็ตรหัสผ่าน** — ผู้ใช้กด "ลืมรหัสผ่าน" เองไม่ได้ เพราะไม่มีอีเมลจริง
เจ้าของระบบต้องตั้งให้ที่ Authentication → Users → คลิกผู้ใช้ → **Reset password**
แล้วแจ้งรหัสใหม่ให้เขาโดยตรง

**ยกเลิกสิทธิ์** — Authentication → Users → คลิกผู้ใช้ → **Delete user**
เขาจะเข้าไม่ได้ทันทีในการโหลดหน้าครั้งถัดไป (session เดิมหมดอายุตามรอบ refresh token)

**ดูว่าใครเข้าล่าสุดเมื่อไหร่** — คอลัมน์ Last sign in ในหน้า Users

## สิทธิ์การใช้งาน

ตอนนี้ทุกคนที่ล็อกอินได้ **แก้ไขข้อมูลได้เท่ากันหมด** (RLS นโยบาย `authenticated_all`)
ทุกไฟล์แนบและทุกงวดงานเปิดให้ทุกบัญชี

ถ้าภายหลังต้องการแยกเป็น "ดูอย่างเดียว" กับ "แก้ไขได้"
ต้องเพิ่มตาราง `nm74.members` (เก็บ user_id + role) แล้วเขียน RLS ใหม่
ให้ policy ของ insert/update/delete เช็ค role — บอกมาได้ครับ
