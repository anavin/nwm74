(เห็นเฉพาะคนที่เป็นแอดมิน) เพิ่ม/ลบ/เปลี่ยนรหัสผู้ใช้ได้จากหน้าเว็บเลย
ไม่ต้องเข้า Supabase อีก

## 2. ใส่คีย์ service_role ใน Vercel

**นี่คือคีย์ที่มีสิทธิ์สูงสุดของฐานข้อมูล ห้ามใส่ใน `config.js` หรือที่ไหนก็ตามที่ขึ้นเบราว์เซอร์**
มันจะอยู่บนเซิร์ฟเวอร์ Vercel เท่านั้น โค้ดในหน้าเว็บไม่มีทางอ่านได้

**คัดลอกคีย์**
Supabase → Project Settings → **API Keys** → หา **service_role** → กดปุ่มก๊อป

**เอาไปใส่ Vercel**
Vercel → โปรเจกต์ **nwm74** → Settings → **Environment Variables** → Add New
เพิ่ม 2 ตัว ติ๊ก Environment ให้ครบทั้ง Production / Preview / Development

| Key | Value |
|---|---|
| `SUPABASE_URL` | URL โปรเจกต์ เช่น `https://xxxxxxxx.supabase.co` (ตัวเดียวกับใน config.js) |
| `SUPABASE_SERVICE_ROLE_KEY` | คีย์ service_role ที่เพิ่งก๊อปมา |

กด **Save**

## ใช้งาน

เข้าเว็บ → เมนูซ้ายจะมี **ผู้ใช้งาน** → ปุ่ม **+ เพิ่มผู้ใช้**

| ช่อง | ใส่อะไร |
|---|---|
| ชื่อผู้ใช้ | ตัวอังกฤษพิมพ์เล็ก/ตัวเลข/`.` `_` `-` ยาว 2–31 ตัว ห้ามเว้นวรรค |
| ชื่อ-สกุล / ตำแหน่ง | ไว้ให้รู้ว่าใครเป็นใคร |
| รหัสผ่าน | อย่างน้อย 6 ตัว |
| สิทธิ์ | ผู้ใช้ทั่วไป หรือ แอดมิน |

กดบันทึกแล้วบอกเจ้าตัวว่า **ชื่อผู้ใช้** กับ **รหัสผ่าน** — เขาพิมพ์แค่ชื่อผู้ใช้
ไม่ต้องพิมพ์โดเมนอะไรทั้งนั้น

**ลืมรหัสผ่าน** — กด "แก้ไข" ที่แถวของเขา แล้วใส่รหัสใหม่ในช่อง "ตั้งรหัสผ่านใหม่"
(เว้นว่างไว้ = ไม่เปลี่ยน)

**ยกเลิกสิทธิ์** — กด "ลบ" ที่แถวนั้น ข้อมูลโครงการไม่หายไปไหน

---

## สิทธิ์

| | แอดมิน | ผู้ใช้ทั่วไป |
|---|---|---|
| ดู/แก้ข้อมูลโครงการ ทุกอย่าง | ✅ | ✅ |
| แนบไฟล์ / ลบไฟล์ | ✅ | ✅ |
| เห็นเมนูผู้ใช้งาน จัดการบัญชีคนอื่น | ✅ | ❌ |

---

## ระบบกันพลาดไว้ให้แล้ว

- ลบบัญชีตัวเองไม่ได้ (ปุ่มลบไม่ขึ้นในแถวของตัวเอง)
- ลดสิทธิ์แอดมินของตัวเองไม่ได้ ต้องให้แอดมินคนอื่นทำ
- ลบแอดมินคนสุดท้ายไม่ได้ ต้องเหลืออย่างน้อย 1 คน
- คนที่ไม่ใช่แอดมิน ต่อให้พิมพ์ URL ตรงเข้าหน้านี้ก็ถูกเด้งกลับ และ API ฝั่งเซิร์ฟเวอร์
  จะปฏิเสธคำขอ (ตรวจสิทธิ์จากโทเคนจริง ไม่ได้เชื่อฝั่งเบราว์เซอร์)

## ยังต้องทำใน Supabase อีก 1 อย่าง

**Authentication → Sign In / Providers → Email**

- ปิด **Allow new users to sign up** — กันคนนอกสมัครบัญชีเอง
- ปิด **Confirm email** — เพราะอีเมลภายในส่งจริงไม่ได้

ถ้าไม่ปิดข้อแรก คนที่รู้ URL จะสมัครบัญชีเองแล้วเห็นข้อมูลโครงการทั้งหมดได้
